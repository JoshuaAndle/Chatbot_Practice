# Project Description
This repository is intended as a coding project to practice RAG for LLM Chatbots.

It includes a simple .ipynb file for demonstrating and testing use cases of the code provided in /src.

When the code is finished I will also include some experiments and results evaluating the impact/importance of different hyperparameters and design choices.


## Data:
Huyen Research Abstracts: https://huggingface.co/datasets/huyen89/researchAbstracts
  - Titles and abstracts of 2100 research papers. Most papers additionally include a generated abstract as well, distinguished in the column 'is_ai_generated'.

## Models
Qwen3-Embedding-0.6B: https://huggingface.co/Qwen/Qwen3-Embedding-0.6B

Qwen2.5-0.5B-Instruct: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct

Qwen3-0.6B: https://huggingface.co/Qwen/Qwen3-0.6B
